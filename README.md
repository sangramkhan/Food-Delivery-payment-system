# Khabar Express - Online Food Delivery

Khabar Express is a modern, responsive web application for online food delivery, created as a lab project for CSE 346.3.

## Project Overview

This project provides a frontend interface for a food delivery platform, featuring:
- A responsive navigation bar with a cart and sign-in options.
- A hero section with a search functionality for finding food near your location.
- Food categories section (Burger, Pizza, Healthy, Dessert).
- A trending menu section showcasing popular items with ratings, prices, and an "Add to Cart" functionality.
- A clean, modern aesthetic utilizing Google Fonts (Poppins) and Font Awesome icons.

## Technologies Used

- **HTML5**: For semantic structure.
- **CSS3**: For styling, layout, and responsive design (Custom variables, Flexbox, Grid).
- **JavaScript**: For interactive elements like the shopping cart functionality.

## Setup Instructions

To run this project locally, simply clone the repository and open the `index.html` file in your preferred web browser. No local server or build tools are required as it uses standard HTML, CSS, and JS.

```bash
git clone <repository-url>
```
Then, double-click `index.html` or drag it into your browser window.

## Features

- **Responsive Design**: The application is fully responsive and works well on desktops, tablets, and mobile devices.
- **Interactive Cart**: The cart counter updates dynamically when items are added.
- **Modern UI/UX**: Clean layout with hover effects and smooth transitions to ensure a great user experience.
